# 后处理

`process.py` 把 `raw/` 里的原始图变成可直接进引擎的成品。顺序固定，不要手工跳过中间步骤。

```
原始图 → 去底 → 裁切 → 补边/统一画布 → 调色锁定 → 多倍导出 → 精灵表
```

## 命令

```bash
python3 scripts/process.py                 # 处理全部素材
python3 scripts/process.py --only knight   # 只处理一个，可重复
```

报告写到 `out/process_report.json`：每个素材的原始尺寸、画布、输出文件、色差。

## 1. 去底

规则：

- 原始图已有透明通道（`alpha.min() < 250`）：原样保留。
- 对象类素材（character / sprite / icon / ui / vfx）没有 alpha：按四边纯色 key 去底。
- 背景（background）和平铺（tile）：默认**不去底**，纯色填充是内容。
- 素材可用 `removeBg: false` 显式关闭。`removeBg` 只在 `transparent: true` 时生效；不透明素材不需要去底。

算法：

1. 取四个角的颜色。
2. 至少 3 个角落在 `tolerance=24` 内，且该颜色覆盖 ≥ 15% 画面，才判定为背景。
3. 把颜色距离在容差内的像素 alpha 设为 0。
4. 对容差 1~2 倍范围内的过渡像素，按估计 alpha 从背景色反混合（去溢色）。

局限：

- 渐变背景、场景背景、复杂光照背景抠不干净。
- 主体内部有与背景同色的区域会被误抠（例如白色背景 + 白色高光）。遇到时改用 `#00FF00` 纯色背景重生，或手工抠图后回填。
- 半透明玻璃、烟雾边缘可能被过度清理。

排查：

| 现象 | 处理 |
|---|---|
| 主体缺一块 | 背景色与主体色太近；换纯色背景重生 |
| 边缘白边 | 去溢色不彻底；重生成，或手工收缩 1px alpha |
| 边缘黑边 | 原图背景是黑色且未完全去除；检查 tolerance |
| 全图被抠空 | 误判背景；对 tile/background 设 `removeBg: false` |

## 2. 裁切

`trim: true` 时按 alpha 包围盒裁掉透明边，不额外留边；安全边距统一由 `padding` 在补边阶段处理。作用：

- 去掉生图工具留下的不规则透明边。
- 让不同来源的素材在统一画布上比例一致。

`trim: false` 用于 tile、背景、精灵帧：这些素材的构图位置是设计的一部分，不能裁。

## 3. 补边与统一画布

- 目标画布 = 单帧尺寸（`width×height` 或 `cell×cell`）。
- 等比缩放到 `(宽−2×padding, 高−2×padding)` 内。
- `anchor`：
  - `center`：居中（图标、UI、特效）。
  - `bottom-center`：底部对齐（角色、精灵）。
  - `top-center`：顶部对齐（少数 UI）。
- 透明素材留透明边；`transparent: false` 的背景用 cover 填满画布，裁掉溢出部分。

## 4. 缩放

| 风格 | 算法 | 原因 |
|---|---|---|
| `style.pixelGrid > 0` 或素材 `pixel: true` | 最近邻（Nearest） | 保持硬边，不产生新颜色 |
| 其它 | Lanczos | 平滑，细节保留好 |

多倍导出：

- 每个倍率都直接从原始图重采样到目标尺寸，避免「先缩到 1x 再放大」的二次插值损失。
- 精灵表统一用 1x 帧拼装；单帧图再按 `scales` 输出。
- 像素风用最近邻，并在缩放后把 alpha 二值化（`harden_alpha`），消除抗锯齿半透明边。
- 原始图应按最大倍数生成，缩小比放大好。

## 5. 调色锁定

`style.paletteLock: true` 时：

1. 取所有 alpha > 0 的像素。
2. 每个 RGB 映射到 `style.palette` 中欧氏距离最近的颜色。
3. alpha 不变。

作用：

- 消除生图工具的颜色漂移。
- 像素风/扁平风统一色板。
- 报告平均色差（`palette_delta`），超过 24 说明原图离色板太远，应该调 prompt 或色板。

注意：

- 写实/手绘不要开 `paletteLock`，会丢层次。
- 色板太小时（少于 6 色）会把细节压平；先扩充色板。
- 量化后再放大，避免放大后出现新颜色。

## 6. 精灵表

多帧素材自动拼装：

- 单元格 = 单帧尺寸（cell 或 width/height）。
- 列数 = `columns`；行数 = `ceil(帧数/columns)`。
- 帧顺序 = `frames` 顺序，从左到右、从上到下。
- 输出 `out/atlas/<id>.png` 和 `<id>.json`。
- `gap` 用于帧间距，默认 0；引擎有 padding 要求时设 2~4。

检查：

- JSON 的 `frames` 数量 = `assets.yaml` 的帧数。
- `cell` = 单帧尺寸。
- `image_size` = 实际图片尺寸。
- 逐帧播放锚点不漂移。

## 7. 平铺接缝修补

`check_assets.py` 报告接缝误差 > 0.08 时：

1. **优先重生成**：prompt 里强调 `seamless tileable texture, edges match, uniform lighting`。
2. **offset-seam 修补**：
   - 把图平移半宽/半高（wraparound），接缝会移到画面中央。
   - 用仿制图章/涂抹/生成修补把中央的缝修掉。
   - 再平移回来。
3. **程序修补**：取左边缘 1~2 列与右边缘做线性混合，上下同理；只适用于纹理较均匀的 tile，会轻微模糊边缘。

不要用「画个边框盖住接缝」的办法，平铺后会看到重复边框。

## 8. 九宫格

UI 素材导出时保留整图，`manifest.json` 和 `使用说明.md` 里写 `nineSlice`。脚本只校验边距合法，不做切图；引擎导入时按边距切片。

设计检查：

- 四角细节完整，不被拉伸。
- 中间区域可平铺，没有不可重复的图案。
- 边线在 2x/3x 下不发虚。

## 9. 常见后处理问题

| 问题 | 原因 | 修法 |
|---|---|---|
| 成品比目标尺寸小 | 原图太小，contain 后留白 | 按最大倍数重生成；或调小 padding |
| 角色被裁掉头/脚 | 原图主体超出画布，trim 后又 contain | 检查原图构图，主体要完整；调 anchor |
| 图标忽大忽小 | 原图主体占比不同 | 统一 padding；必要时手工调 `size.padding` |
| 2x 图出现新颜色 | 放大用了 Lanczos 或量化顺序错 | 像素风用最近邻；先量化再放大 |
| 精灵表坐标对不上 | columns/帧数不匹配 | 重跑 process.py；检查 JSON |
| tile 接缝越修越明显 | 只模糊了边缘 | 用 offset-seam 或重生成 |
| 背景变成透明 | 误开了 removeBg | 背景/tile 设 `removeBg: false` |
| 色板锁定后发灰 | 色板缺中间色 | 扩充色板，补 2~3 个中间明度 |
