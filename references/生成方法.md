# 生成方法：ai-image 与 code-draw

每个素材在 `assets.yaml` 里用 `mode` 选择生成方式。两种模式产出都落到 `raw/<type>/<id>/<frame>.png`，后处理完全共用。

## 怎么选

```
需要写实材质 / 复杂光影 / 手绘笔触？
├─ 是 → ai-image（有生图能力直接生成；没有就导出 prompt 包）
└─ 否 → 主体是否几何化、色板有限、需要像素级对齐？
    ├─ 是 → code-draw（SVG 优先，UI/Canvas 次之）
    └─ 否 → 先试 code-draw 画锚点，用户不满意再转 ai-image
```

补充规则：

- **像素风、扁平风、UI、文字框、几何图标**：code-draw 更稳，尺寸和色板完全可控。
- **写实角色、场景背景、自然纹理、复杂特效**：ai-image 更合适。
- **AI 工具没有生图能力**：只用 code-draw，或导出 prompt 包让用户回填；不要在没能力的情况下假装"生成"。
- **同一套素材尽量统一模式**：图标全 code-draw 或全 ai-image，混用容易描边和光照不一致。

## ai-image

### Prompt 结构

每份 `prompts/<id>.md` 由 `plan.py --prompts` 生成，固定包含：

1. 元信息：类型、目标尺寸、倍数、背景、帧、回填路径。
2. 风格块：`style.json` 编译出的关键词、色板、描边、光照、材质、负向词。
3. 构图要求：按素材类型给的具体构图。
4. 素材描述：`assets.yaml` 里的 `prompt` 或 `notes`。

### 手写 prompt 模板

```text
<主体描述：谁/什么，在做什么，朝向，关键特征>
<画种与质感：16-bit pixel art / flat vector / painterly...>
Style: <style.keywords 逗号连接>
Palette: #1A1C2C, #B13E53, #FFCD75, ...（只使用这些颜色）
Line: <style.line>
Lighting: <style.lighting>
Material: <style.material>
Composition: single <type> centered, full body, feet at bottom, 70-85% of canvas,
isolated on transparent background, no backdrop, no text, no watermark.
Resolution: <width*max_scale>x<height*max_scale>, crisp edges.

Avoid: <style.avoid 逗号连接>, extra objects, cropped limbs, frame, border,
signature, logo, text, watermark, jpeg artifacts.
```

### 示例：像素图标

```text
A red healing potion bottle, round body, cork stopper, small bubbles inside,
front view, single object.
16-bit pixel art, crisp integer pixels, limited palette.
Style: 16-bit pixel art, crisp integer pixels, limited palette, retro adventure game
Palette: #1A1C2C, #B13E53, #EF7D57, #FFCD75, #73EFF7, #F4F4F4
Line: 1px dark outline, no anti-aliasing
Lighting: top-left key light, hard-edged shadow, no soft gradients
Composition: single icon centered, 70-85% of canvas, transparent background,
no backdrop, no text, no watermark.
Resolution: 512x512.
Avoid: 3d render, blurry, photo texture, text, watermark, anti-aliasing,
soft gradient, multiple objects.
```

### 多帧一致性

1. **先做身份锚点**：第一帧（idle）单独生成，让用户确认比例、服装、配色。
2. **有参考图能力**：把第一帧作为参考图，逐帧生成；提示词里写 `same character, same outfit, same proportions`。
3. **没有参考图能力**：每帧 prompt 都完整重复服装、发型、配色、身高、头身比；不要只写「同上」。
4. **生成顺序**：idle → walk → attack → 其它；动作幅度从大到小检查。
5. **后处理**：所有帧统一画布、统一 anchor，脚底基线由脚本保证；身份一致性仍需人眼审。

### 透明底

- prompt 必须写 `isolated on transparent background, no backdrop`。
- 生图工具不支持透明时：用纯色背景（推荐 `#00FF00` 或 `#FFFFFF`），后处理 `remove_solid_bg` 会抠掉并去溢色。
- 不要用渐变背景或场景背景，后处理无法可靠抠除。
- 生成后检查边缘：白边/黑边说明去溢色不彻底，需要重生成或手工修。

### 没有生图能力时

```bash
python3 scripts/plan.py --prompts
```

把 `prompts/<id>.md` 交给用户，让他用任意生图工具生成，按文件里的回填路径放到 `raw/<type>/<id>/<frame>.png`。然后跑：

```bash
python3 scripts/plan.py --check-raw
python3 scripts/process.py
```

缺图时 `--check-raw` 会逐项列出，不要跳过去处理别的素材。

## code-draw

### SVG（首选）

约定：

- 文件：`codegen/src/<id>.svg`；多帧：`<id>__<frame>.svg`。
- `width/height/viewBox` 用目标单帧尺寸的整数倍，所有形状落在整数坐标。
- 背景透明：不要画铺满画布的底色；需要底色时确保 `transparent: false`。
- 颜色只取 `style.json` 色板。
- 像素风加 `shape-rendering="crispEdges"`，不用渐变、模糊、阴影滤镜。
- 不要引用外部图片、字体、CSS；全部内联。

示例（32×32 像素药水瓶，渲染成 128×128）：

```svg
<svg xmlns="http://www.w3.org/2000/svg" width="32" height="32" viewBox="0 0 32 32">
  <g shape-rendering="crispEdges">
    <rect x="13" y="3" width="6" height="4" fill="#EF7D57"/>
    <rect x="14" y="7" width="4" height="5" fill="#73EFF7"/>
    <rect x="9" y="12" width="14" height="18" fill="#1A1C2C"/>
    <rect x="10" y="13" width="12" height="16" fill="#73EFF7"/>
    <rect x="11" y="18" width="10" height="10" fill="#B13E53"/>
    <rect x="13" y="21" width="2" height="2" fill="#FFCD75"/>
    <rect x="11" y="14" width="2" height="6" fill="#F4F4F4"/>
  </g>
</svg>
```

`render.py` 会用 ImageMagick 按最大倍数渲染，像素风自动加 `-filter point`。

### HTML / Canvas

约定：

- 文件：`codegen/src/<id>.html`；多帧优先 `<id>__<frame>.html`，否则同一个 HTML 处理 `?frame=`。
- 页面会收到 `?frame=<frame>&scale=<scale>&w=<w>&h=<h>`。
- 页面尺寸就是单帧 CSS 尺寸；`device_scale_factor=scale` 负责输出最大倍数。
- 背景必须透明：`body { background: transparent; margin: 0 }`。
- 只用本地资源；不要 `fetch` 外部地址。
- 像素风关闭 canvas 抗锯齿：`ctx.imageSmoothingEnabled = false`。

示例：

```html
<!doctype html>
<html>
<head>
<meta charset="utf-8">
<style>
  html, body { margin: 0; padding: 0; background: transparent; overflow: hidden; }
  canvas { display: block; }
</style>
</head>
<body>
<canvas id="c"></canvas>
<script>
  const params = new URLSearchParams(location.search);
  const w = Number(params.get('w') || 128);
  const h = Number(params.get('h') || 128);
  const frame = Number(params.get('frame') || 0);
  const palette = ['#1A1C2C', '#B13E53', '#EF7D57', '#FFCD75', '#73EFF7', '#F4F4F4'];
  const canvas = document.getElementById('c');
  canvas.width = w; canvas.height = h;
  const ctx = canvas.getContext('2d');
  ctx.imageSmoothingEnabled = false;
  const u = w / 32; // 32 格设计稿
  ctx.fillStyle = palette[0];
  ctx.fillRect(9 * u, 12 * u, 14 * u, 18 * u);
  ctx.fillStyle = palette[4];
  ctx.fillRect(10 * u, 13 * u, 12 * u, 16 * u);
  ctx.fillStyle = frame % 2 ? palette[1] : palette[2];
  ctx.fillRect(11 * u, 18 * u, 10 * u, 10 * u);
  ctx.fillStyle = palette[3];
  ctx.fillRect(13 * u, 21 * u, 2 * u, 2 * u);
</script>
</body>
</html>
```

渲染：

```bash
python3 scripts/render.py --id potion_red --force
```

### 色彩与描边

- 先从 `style.json` 的 `palette` 里挑 3~5 个角色：暗色描边、主色、亮部、强调色。
- 描边宽度统一（像素风 1 格，Q 版 3~4px），不要每张单独调。
- 光照方向统一（默认左上），高光和阴影画在同一侧。
- 颜色数量控制：像素风不超过色板；扁平风尽量 5~8 色。

### 代码绘制不适合什么

- 写实皮肤、毛发、布料褶皱、自然火焰/烟雾。
- 大量有机曲线和随机细节。
- 需要手绘笔触或水彩晕染的效果。

遇到这些，转 `ai-image`，或只用 code-draw 做底板/边框，主体交给生图。

## 版权与原创

- 不生成受版权保护的现成 IP（马里奥、宝可梦、原神、迪士尼角色等），也不做「换个颜色就算原创」的擦边。
- 用户提供参考图时，只提取风格特征（色板、描边、构图），不复制具体角色设计。
- 用户要求临摹某 IP 时，明确说明风险，改成原创设计或要求用户提供授权证明。
