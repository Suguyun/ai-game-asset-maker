# 校验清单

交付前必须同时通过**自动闸门**和**人眼审图**。自动闸门只能查尺寸、透明、接缝、坐标这类确定性问题；风格是否统一、主体是否可读、角色是否像同一个人，必须看联系表。

## 命令

```bash
python3 scripts/check_assets.py     # 0 ERROR 才能继续
python3 scripts/sheet.py            # 生成 out/sheet.jpg 和 out/sheets/<type>.jpg
```

报告：

- `out/check_report.json`：逐素材的 ERROR / WARN / 说明。
- `out/sheet.jpg`：全部成品总览。
- `out/sheets/<type>.jpg`：分类预览。

## 自动闸门

| 检查 | 级别 | 触发条件 | 修法 |
|---|---|---|---|
| 缺文件 | ERROR | 矩阵中的文件不存在 | 跑 process.py，或检查 raw |
| 尺寸 | ERROR | 实际尺寸 ≠ 单帧尺寸 × 倍数 | 检查 size 配置和原始图 |
| 透明 | ERROR | 对象类素材无透明像素 | 去底，或改 `removeBg` |
| 内容 | ERROR | tile/background 不透明像素 < 30% | 检查是否被误抠空 |
| 图标主体大小 | WARN | 包围盒较长边占画布 < 70% 或 > 95% | 调 padding / 重新构图 |
| 图标安全边距 | ERROR | 主体进入 padding 区域 | 调 padding 或重生成 |
| 角色基线 | ERROR | 各帧最底非透明行差 > 2px | 统一 anchor，检查每帧脚底 |
| 图集缺失 | ERROR | 多帧素材缺 atlas png/json | 重跑 process.py |
| 图集尺寸/帧数/单元格 | ERROR | 与元数据不一致 | 重跑 process.py，检查 columns |
| 平铺接缝 | ERROR | `seam_error > 0.08` | 重生成或用 offset-seam |
| 九宫格 | ERROR | `left+right >= width` 或 `top+bottom >= height` | 调 nineSlice |
| 像素风半透明 | WARN | 1x 图半透明像素 > 1% | 关闭抗锯齿，检查 SVG/Canvas |
| 像素风颜色数 | WARN | 颜色数 > max(16, 色板数) × 3 | 开 paletteLock，检查 code-draw 用色 |
| 色板距离 | WARN | 主色到最近色板平均距离 > 24 | 调 prompt / 扩色板 / 开 paletteLock |
| 背景透明像素 | WARN | 声明不透明但含透明像素 | 补满背景或改 transparent |

ERROR 必须清零；WARN 逐条判断，能修就修，不能修要写进 `设计说明.md` 的已知限制。

## 人眼审图清单

打开 `out/sheet.jpg`，按下面逐项看。建议先看总览，再打开分类图放大。

### 通用

- [ ] 和风格锚点比，配色、描边、光照、材质是否一致？
- [ ] 有没有文字、水印、签名、多余背景残留？
- [ ] 主体是否完整？有没有被裁掉头、手、脚、武器？
- [ ] 缩到游戏里实际显示尺寸（32~64px）还认得出吗？
- [ ] 同套素材并排看，像同一个世界的东西吗？
- [ ] 有没有明显重复/镜像凑数？

### 角色 / 精灵

- [ ] 各帧身高、头身比、服装、发型、配色一致？
- [ ] 脚底基线一致？动作不超出单元格？
- [ ] 待机、行走、攻击的朝向一致？
- [ ] 武器/道具换手了吗？披风/裙摆长度变了吗？
- [ ] 逐帧播放（或并排看）动作连贯吗？

### 图标

- [ ] 同套图标的描边粗细、光源方向、留白一致？
- [ ] 主体占画布比例一致？没有忽大忽小？
- [ ] 剪影清晰？复杂细节缩到 32px 还看得见吗？
- [ ] 透明边缘干净？没有白边/黑边？
- [ ] 同功能的图标风格统一（药水、武器、技能）？

### 背景

- [ ] 无文字、无 UI、无水印？
- [ ] 中央区域不会和角色/界面打架？
- [ ] 明暗对比是否抢主体？
- [ ] 分辨率够目标平台？边缘可裁切？

### 平铺

- [ ] 3×3 平铺预览无可见缝？
- [ ] 四边光照一致？没有方向性阴影？
- [ ] 中间没有强焦点导致重复感？
- [ ] 透明 tile 的主体纹理铺满，不透明像素 ≥ 30%？

### UI

- [ ] 拉到 2~3 倍，四角不变形、边线不糊？
- [ ] 九宫格边距把角切在细节之外？
- [ ] 中间区域可平铺，没有不可重复图案？
- [ ] 透明区域干净？

### 特效

- [ ] 帧间位置、尺寸、配色稳定？
- [ ] 首尾可循环（如果是循环特效）？
- [ ] 锚点与游戏内挂点一致？
- [ ] 缩到实际尺寸仍有冲击力？

## 联系表审图流程

1. 先跑 `check_assets.py`，ERROR 清零。
2. 跑 `sheet.py`，打开总览。
3. 按类型逐组看；有问题的素材记下 id。
4. 对照 `out/sheets/<type>.jpg` 放大看细节。
5. 需要看单张时直接打开 `out/assets/<type>/<file>@1x.png`。
6. 每轮修复后重跑 1~2 步；不要只改图不重跑校验。

## 交付前检查

- [ ] `check_assets.py` 0 ERROR。
- [ ] `out/sheet.jpg` 已逐张看过，问题已修或记录。
- [ ] `process_report.json` 无失败项。
- [ ] `manifest.json` 的素材数与 `assets.yaml` 一致。
- [ ] `素材清单.md` 的尺寸/帧数正确。
- [ ] `使用说明.md` 的命名、图集、九宫格说明与实际一致。
- [ ] `预览/联系表.jpg` 是最新版。
- [ ] 旧版成品已备份到 `工程/out/第N版/`（改版时）。
- [ ] 没有把临时文件、raw 大图、渲染日志放进交付目录。

## 什么时候停下来问用户

- 同一素材连续两次被否，且原因说不清（风格不对味、形状不喜欢）。
- 去底失败且没有干净背景可重生成。
- 用户要求临摹受版权保护的 IP。
- 尺寸/帧数与引擎导入要求冲突，无法两全。
- 缺少参考图，AI 生图无法稳定角色身份。

停下来时给出两个具体选项（例如「换 code-draw 重画」 vs 「你给一张参考图」），不要只问「怎么办」。
